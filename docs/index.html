Clang-Format Aligned Comment Toggler

This is the official Eclipse Update Site for the Clang-Format Aligned Comment Toggler plugin.

How to Install in Eclipse

  1. In Eclipse, go to Help > Install New Software...
  2. Copy and paste this page's URL into the Work with: field:
    https://htanwar922.github.io/io.github.htanwar922.eclipse.clangformat/
  3. Press Enter, check the box next to C/C++ Formatting Tools, and click Next.
  4. Follow the on-screen prompts to complete installation and restart Eclipse.

For source code, issue tracking, and documentation, visit the GitHub Repository.
